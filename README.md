# Quiz Pokédex

Nomme tous les Pokémon (noms FR ou EN), façon pkmnquiz.com. Ouvrir `index.html`.

- Pages façon Pokédex : **National** (1025) + une page par région (Kanto → Paldea)
- Validation automatique à la frappe (Entrée pour forcer)
- Indices de types : toggle global, filtre par type, ou clic sur une case
- Progression sauvegardée dans le localStorage

Données : `pokemon-data.js` (noms), `types-data.js` (types, depuis PokeAPI).
Sprites chargés depuis le dépôt PokeAPI/sprites (connexion requise).
